# About tdx-tool

This tool aim to wrapped TDX api in a pythonic way, you can directly access without reading TDX document. 

For static data, you can get a analyze-ready data in the format of `DataFrame`(pandas), `GeoDataFrame`(geopandas), or `DataArray`(xarray). In another hand, you can fetch real-time data including download and process just a few lines.

## Installing

You can install this tool by:

1. By pip
```python
>>> pip install tdx-tool
```

2. By conda package manager:
```python
>>> conda install tdx-tool
```

## Feature

- Support IDE Hinting
- Static type checkable
- Automatically refresh access token
